## 2️⃣ API 封装更新 —— `src/api/system-manage.ts`

### 2.1 ⚠️ 必须最先同步：`createMenu` / `updateMenu` 新签名（旧调用 404）

后端函数签名已变（PostgREST 按参数名匹配，旧封装缺参数将 PGRST202 404）：

```ts
// createMenu 16 参（新增 p_remark/p_route_name/p_query/p_is_link/p_is_iframe/p_redirect/p_keep_alive）
export function createMenu(params: {
  p_menu_name: string
  p_parent_id?: string | null
  p_menu_type?: 'directory' | 'menu' | 'button' | 'link' // ⚠️ 类型加 'link'
  p_perms?: string | null
  p_path?: string | null
  p_component?: string | null
  p_icon?: string | null
  p_order_num?: number
  p_is_visible?: boolean
  p_remark?: string | null
  p_route_name?: string | null
  p_query?: string | null
  p_is_link?: boolean | null
  p_is_iframe?: boolean | null
  p_redirect?: string | null
  p_keep_alive?: boolean | null
})

// updateMenu 同理 +7 参（p_id 之后）
// 注意：p_menu_type 传 'link' 时后端自动置 is_link=true；改离 link 需显式传 p_is_link=false
```

### 2.2 新增 4 个接口

```ts
/** 角色数据范围查询（sys:data-scope:bind） */
getRoleDataScope(roleCode: string)
  → POST rpc_get_role_data_scope { p_role_code } → RoleDataScope

/** 角色数据范围设置（全量覆盖；custom 时 p_dept_ids 必填） */
setRoleDataScope(roleCode: string, scopeType: RoleDataScope['scope_type'], deptIds?: string[])
  → POST rpc_set_role_data_scope { p_role_code, p_scope_type, p_dept_ids }

/** 一键授权：授予角色「菜单及全部子孙菜单归属的 API」增量（sys:role-api:bind） */
grantMenuSubtreeApis(roleCode: string, menuId: string)
  → POST rpc_grant_menu_subtree_apis { p_role_code, p_menu_id } → { ok, granted, total }

/** 一键撤销（对称，前端取消勾选场景） */
revokeMenuSubtreeApis(roleCode: string, menuId: string)
  → POST rpc_revoke_menu_subtree_apis { p_role_code, p_menu_id } → { ok, removed }
```

## 3️⃣ 菜单路由消费 —— `src/router/core/MenuProcessor.ts`

## 4️⃣ 菜单管理页 —— `src/views/system/menu`

1. **表单新增 7 个字段**：备注（textarea）、路由名称、路由参数、是否外链（switch）、是否 iframe（switch）、重定向路径、页面缓存（switch）。提交时透传 2.1 新参数。
2. **menu_type 下拉加 'link'**：选中 link 时——path 必填且须 `http(s)://`（后端 CHECK 约束，违反报 23514）、component 置空、自动勾选外链。
3. **button 类型 perms 必填**（前端表单校验；后端违反报 22023 `button menu requires perms`）。
4. **perms 软提示**：录入 perms 时若与 `iam_api.api_code`（GET /iam_api?select=api_code 拉取）无对应，提示"建议先建权限点再配按钮（单码制对齐）"——仅提示不阻断。
5. 表格列可选展示：备注、路由名称、缓存。
